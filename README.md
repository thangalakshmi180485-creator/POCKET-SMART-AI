# PocketSmart: An AI-Powered Smart Budget Planner Framework

PocketSmart is an enterprise-grade digital financial coordinator engineered using the **FastAPI ASGI framework** and **Bootstrap 5 UI Engineering**. It automates budget tracking for modern lifestyle events like home interiors, ceremonial parties, and jewelry procurement by calculating precise micro-allocations based on user budget constraints.

## 🚀 Core Software Architecture Matrix
- **Backend Infrastructure Suite:** Python, FastAPI, Uvicorn ASGI Server, Pydantic Schema Enforcers
- **Frontend Client Interface:** Bootstrap 5 Framework, JavaScript Node Processing, Font-Awesome Icons
- **Ecosystem Supply Chain Interceptors:** Live integrated query deep-links directly routing to global market indexes including Amazon, Flipkart, Ikea, Swiggy, Zomato, and CaratLane.

## 🛠️ Local Environment Initialization Guide
To spawn and test this multi-module unified routing architecture locally, execute the following commands inside your terminal:

```bash
# Install the mandatory software infrastructure dependencies
pip install fastapi uvicorn pydantic

# Run the master ASGI microserver engine
python app.py
```

Once initialized, navigate to `http://127.0.0` in your browser to access the live landing dashboard view matrix.
